# ESP32-Handson
ESP32 programming and component interfacing using Arduino IDE

## Project Title
ESP32 Programming and Interfacing

## About
This repository contains my ESP32 programs and component interfacing
using Arduino IDE.

## Tools & Technologies
- ESP32
- Arduino IDE
- C/C++

## Components
- DHT11
- Ultrasonic Sensor
- OLED
- I2C LCD
- Servo Motor
- Relay
- Buzzer
- Bluetooth

## How to Use
1. Open the `.ino` file in Arduino IDE.
2. Select the ESP32 board.
3. Connect the required components.
4. Upload the code.
5. Check the output.

## Conclusion
This repository contains my practical work with ESP32 and different
electronic components.
